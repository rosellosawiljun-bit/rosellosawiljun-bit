# Jerome Burce — React Portfolio

A responsive, interactive developer portfolio built with React + Vite.

## Features

- Responsive single-page layout
- Dark/light theme toggle
- Smooth scrolling navigation
- Mobile navigation menu
- Scroll reveal animations
- Interactive project filters
- Interactive skill filters
- Skill progress visualization
- Professional experience timeline
- Contact section
- No UI framework required

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Customize

1. Replace `your-email@example.com` in `src/main.jsx`.
2. Update project descriptions in the `projects` array.
3. Update the `timeline` array with any additional experience.
4. Adjust skills/levels in the `skills` array.
5. Change colors and spacing in `src/styles.css`.

## Build for production

```bash
npm run build
```
